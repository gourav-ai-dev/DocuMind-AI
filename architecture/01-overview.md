
📗 DocuMind AI — Overview

🧑‍💻 Project Description
DocuMind AI is a document-based AI chatbot that lets users upload files (PDF, TXT, CSV, and code files) and ask questions about them in plain language.

It uses a Retrieval-Augmented Generation (RAG) approach along with agent-based logic to return relevant and accurate answers.

🥅 Goals
Deliver fast and accurate responses from uploaded documents
Support multiple file formats
Keep the system scalable and modular
Allow flexible configuration of models and behavior
Build a production-style project that stands out to recruiters

🔑 Key Capabilities
Supports multiple documents at once
Answers questions based on document context
Maintains chat history
Uses a configuration-driven setup
Works with different LLM providers (Ollama, OpenAI, etc.)

⚱️ Non-Functional Requirements
Low response time
Reliable and accurate retrieval
Scalable system design
Clean and maintainable code
Easy to extend in the future

💻 System Components
Frontend: React UI
Backend: .NET API
AI Layer: FastAPI with LangChain and LangGraph
Database: SQL Server


🔥 Why This Project Stands Out

This project is more than just a chatbot. It combines:
  Agent-based workflows using LangGraph
  Custom vector storage built on SQL Server
  A configuration-driven AI setup
  A hybrid architecture using .NET and Python

It reflects how real-world AI systems are designed and built.
